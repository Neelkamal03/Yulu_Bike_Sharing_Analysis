# Yulu Bike Sharing Analysis

## Project Overview
An Exploratory Data Analysis (EDA) project on Yulu's bike-sharing dataset to identify factors influencing rental demand and generate actionable business insights.

## Objectives
- Analyze bike rental demand across different seasons and weather conditions.
- Identify peak rental hours and usage patterns.
- Compare customer behaviour on working days and holidays.
- Understand factors affecting overall rental demand.
- Provide data-driven business recommendations.

## Tech Stack
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Google Colab

## Dataset
The dataset contains rental records, weather conditions, temperature, humidity, seasonal and customer information.

## Analysis
- Data cleaning and preprocessing
- Exploratory Data Analysis
- Univariate and Bivariate Analysis
- Correlation Analysis
- Data Visualization

## Business Insights
- Improve bike availability and fleet allocation.
- Optimize operational planning.
- Understand weather-based demand patterns.
- Develop better customer engagement strategies.

## How to Run
1. Open the notebook in Google Colab.
2. Load the dataset using the provided GitHub CSV link.
3. Run all cells sequentially.
